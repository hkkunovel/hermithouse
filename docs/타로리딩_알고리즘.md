# 타로리딩 알고리즘

```
질문 입력
    ↓
[STEP 1] 카테고리 분류
    키워드 매칭 → 💫 연애·관계 / 📖 직업·학업 / 🔮 기타
    직업 키워드 우선 (동점 시 직업 > 연애)
    ↓
[STEP 2] 카드 3장 테마 추출
    각 카드 → 15개 테마 중 하나로 분류
    (new / ending / growth / choice / inner / change /
     shadow / connect / power / balance /
     passion / emotion / conflict / material / persist)
    ↓
[STEP 3] intent 의도 파악 ────────────────── 매칭되면 → 출력 (50개)
    우선순위 순서로 체크:
    1. compare  → "중에, 둘 중, 더 나을, vs, 비교..."
    2. when     → "언제, 시기, 타이밍, 기다..."
    3. how      → "어떻게, 방법, 어떡해..."
    4. why      → "왜, 이유, 원인..."
    5. who      → "누구, 어떤 사람..."
    6. possible → "될까, 잘될, 가능, 합격할..."
    7. advice   → "해야, 조언, 어찌해..."

    의도 감지 시 → 상대방/상황 키워드도 함께 추출
    (남자친구, 걔, 면접, 취업, 상사 등)
    → 카테고리 × 미래카드 테마 조합으로 메시지 선택
    → 키워드 있으면 단어를 문장에 삽입, 없으면 일반 문장
    ↓ 없으면
[STEP 4] exact 조합 체크 ──────────────────── 매칭되면 → 출력 (117개)
    과거테마-현재테마-미래테마 키로 조회
    카테고리별 분기: exactLove / exactWork / exactEtc
    ↓ 없으면
[STEP 5] 카테고리별 기본 메시지 ─────────── 출력 (75개)
    연애 30개 / 직업 30개 / 기타 15개
    미래 카드 테마 기준으로 선택
    → 상황 키워드 있으면 단어 삽입, 없으면 일반 문장
    ↓ 없으면
[STEP 6] 폴백 ───────────────────────────── 출력 (1개)
    "{과거카드명}의 흔적 위에 {현재카드명}의 에너지가 더해져,
     {미래카드명}이 가리키는 방향으로 나아가고 있습니다."

총 243개 메시지 (모바일 폴백으로 사용)
(exactLove 39 + exactWork 39 + exactEtc 39 + intent 50
 + byLove 30 + byWork 30 + byEtc 15 + 폴백 1)

    ↓ (위 메시지는 숨김, 데이터만 유지)

[AI 리딩] Claude API 호출 ───────────────── 화면에 표시
    질문 원문 + 카테고리 + 카드 3장(이름·의미) → Claude Sonnet
    → 과거→현재→미래 흐름을 내러티브로 생성
    → 질문 상황에 직접 연결, 감성적 2인칭 어투, 3~5문장
    API 실패 시 (모바일 등) → STEP 3~6 결과를 폴백으로 표시

    ↓ (선택)

[조언 듣기] 카드 3장 추가 뽑기 ──────────
    기존 3장 제외, 나머지 75장에서 3장 추가
    → 방해물 / 주변환경 / 조언 순서로 배치
    → Claude API로 5장 통합 해석
    API 실패 시 → 각 카드 reading 텍스트 조합으로 폴백 표시
```
